# `BaseE2eTest.cs` changed after CAT-01's test baseline was taken — accept the change for this story?

## Question

The test gate refuses CAT-01 (`tests-kept`): `tests/DcaShop.E2eTests/BaseE2eTest.cs` "no longer expects what it
did", and the plan's `## Changed tests` does not list it. The test stage did not touch that file. It changed in
commit 5c2bb69 ("test(e2e): the browser suite starts the shop itself, in the test process, on a free port",
2026-09-26 08:03 +0200). The story's test baseline (`tasks/CAT-01/.tests-baseline`) was recorded by the first
plan gate at 2026-09-26 00:25, before that commit, and a baseline is written only once per story. Does the
change count as accepted for CAT-01?

## Evidence

- `tasks/CAT-01/.tests-baseline:4` — blob `de5df50` for `tests/DcaShop.E2eTests/BaseE2eTest.cs`.
- `git diff de5df50 HEAD:tests/DcaShop.E2eTests/BaseE2eTest.cs` changes two lines:
  - `BaseUrl` was `Environment.GetEnvironmentVariable("E2E_BASE_URL") ?? "http://localhost:5080"` and is now
    `ShopUnderTest.BaseUrl`
  - the `Browser` guard's message lost "— is E2E_BASE_URL set?"
- `git status` shows `BaseE2eTest.cs` has no working-tree change. HEAD holds what the gate sees.
- `SeededCatalogE2eTest#CatalogListsTheSeededProductsInNameOrder` (the mapped happy-path test) passes on HEAD
  as it is (gate report, `tests-green`).

## Options

1. **Accept the change for CAT-01.** It was committed separately, is infrastructure, not behaviour, and
   predates this stage. Answering this record satisfies `tests-kept` at the test stage, and nothing else
   changes.
2. **Re-plan with a fresh baseline.** Delete `tasks/CAT-01/.tests-baseline` and run the plan stage again, so the
   baseline is HEAD at 5c2bb69.
3. **Restore the old lines in `BaseE2eTest.cs`.** This undoes commit 5c2bb69's self-hosting E2E setup.
   Not advised.

## Recommendation

Option 1. The change belongs to a commit made outside this story, and the story's own tests pass on it.
Option 2 does the same thing but costs a plan round.

## Answer
answer: a — accepted: the change came from a commit outside this story (the browser suite now starts the shop itself); the story's own tests pass on it.

at: 2026-09-26T06:40:42Z
rationale: A run commits nothing while a story is open; the gate treats a committed change as someone else's since 0.39.4.
