# May this task move assertion statements out of existing test files into shared test support?

## Question
Three of the rows this task closes are fixed by lifting copied test helpers into one shared place, and each copy
carries an assertion statement. A task may change an existing test file only around its assertions (`tests-kept`):
every assertion statement the file had must still be in it. Moving the helper takes the statement with it, so the
build gate refuses these files unless the plan lists them under `## Changed tests`, backed by an answered decision.
No assertion is weakened or changed in value; each moves into shared test support, or appears once instead of four
times.

- taking-over-the-guest-cart-is-a-step-of-its-own#6: `TakeOverForm` moves out of
  `tests/DcaShop.IntegrationTests/CartTakeOverPageTest.cs` into `TakeOverForm.cs`, and takes
  `Assert.True(action.Success, "the page has the take-over form")` (`:76`) with it.
- taking-over-the-guest-cart-is-a-step-of-its-own#5: `TakeOverForm.FollowAsync(browser, location)` replaces the
  round trip that opens the page, asserts `OK`, sends the form and asserts `Redirect`, in
  `tests/DcaShop.IntegrationTests/AccountFlowTest.cs:63-66`,
  `tests/DcaShop.IntegrationTests/CartStaysWithThePersonTest.cs:155-158` and
  `tests/DcaShop.IntegrationTests/CartRecoveryOnLoginTest.cs:408-411`.
- an-unusable-cart-request-is-a-problem-document#1: `OpenCartForNewCustomerAsync` in
  `tests/DcaShop.E2eTests/CartApiE2eTest.cs` asserts `Created` once, in place of the four copies at `:30`, `:50`,
  `:70` and `:93`.

The other ten rows fit the rule as they are. They add tests, rename a test, or remove helpers that hold no assertion.

## Options
- a: The plan gains `## Changed tests` with these five files, each row citing this decision. The build moves the
  assertions as listed and closes all thirteen rows. This costs one plan re-run.
- b: Take the three rows out of `closes:` and leave them open for a story of their own. The task closes the other
  ten, and the copies stay as they are.
- c: Keep the rows, but keep each assertion statement in its test file. The callers assert what the shared helper
  answers, so `FollowAsync` only opens the page and sends the form, and `TakeOverForm` stays where it is. Two of the
  rows are then only half fixed.

## Recommendation
a: every assertion keeps its words and values and only changes place, which is what the three rows ask for. The
plan's `## Changed tests` is where the gate looks for that backing.

Evidence: `tests-kept` as `.claude/skills/factory-run/reference/file-contracts.md` states it, under *Tests that
existed before the story*. Sibling question: `the-checkout-tests-findings-are-closed-01`.
