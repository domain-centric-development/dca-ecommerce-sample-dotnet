# Which feature holds the ResumeCheckout use case — Session, as planned, or CheckoutCompletion?

## Question

The plan's `## Files` places `ResumeCheckout` (`IResumeCheckoutInputPort`, command, result, use case) under
`src/DcaShop.Checkout/Application/Session/ResumeCheckout/`. Its only caller is the step pages' shared helper
`CheckoutStepPage`, built by the five step-page controllers in `Adapter/Incoming/Web/CheckoutCompletion/`, which
already drive CheckoutCompletion's commands (`ISubmitBuyerInfoInputPort`, `ISubmitDeliveryInputPort`,
`ISubmitPaymentInputPort`, `IConfirmCheckoutInputPort`). Built as planned, the architecture suite fails:

`[DCA-USE-018] …DeliveryPageController drives the commands of 2 features: CheckoutCompletion (ISubmitDeliveryInputPort); Session (IResumeCheckoutInputPort)` — and the same for the buyer, payment and confirmation pages.

Built under `Application/CheckoutCompletion/ResumeCheckout/` instead, the code compiles, the story's tests pass and
the rule holds; but the build gate's `plan-files` check refuses it, because the plan names the Session paths.

## Options
- a: Plan again with `ResumeCheckout` under `Application/CheckoutCompletion/ResumeCheckout/`.
  Resuming the checkout is what a step page does on the way to completing it; the four built files are already
  there and green. Costs: a new plan round naming the four paths.
- b: Keep `Session` and split the step-page adapters so the resume is driven by an adapter of its own.
  Costs: a new incoming adapter class for one GET fallback, and the step pages lose their single entry point.
- c: Keep `Session` and drive the command from a class the rule does not see as the controllers' (e.g. resolve the
  port inside `CheckoutStepPage` from the request services).
  Costs: satisfies the rule's letter while breaking its intent — a determinism gap, not a fix.

## Recommendation
a — the step pages are CheckoutCompletion's adapters, and DCA-USE-018 says an adapter drives one feature's commands; the feature that owns those pages owns the command they drive.

## Answer
answer: a
