# How may a story retire a browser test that the spec still names until delivery?

## Question

The story removes the scenarios `paying-again-for-the-same-amount-keeps-the-payment` and moves
`authorized-payment-moves-to-review` and `the-payment-request-names-its-checkout` to port-level tests. So the browser
tests `PayingAgainE2eTest#PayingAgainForTheSameAmountKeepsTheAuthorizedPayment`,
`ProviderPaymentE2eTest#APaymentTheProviderAuthorizesLeadsOnToTheReview` and
`PaymentNamesItsCheckoutE2eTest#ThePaymentRequestCarriesTheCheckoutSessionAsItsMerchantReference` are gone or renamed.
`product/spec/checkout/payment/scenarios.md` still names them in its `Test:` lines, and only the delivering gate writes
the spec. `tests/DcaShop.UnitTests/Specification/SharedScenariosTest.cs:79` (`EveryBrowserTestAScenarioNamesExists`)
therefore fails, and the build gate refuses the unit suite. The test is outside the story's change, so the build may
not edit it, and the plan does not list it. Everything else at the build gate is green.

## Options
- a: Change `SharedScenariosTest` so a `Test:` line need not exist while a story that is not delivered yet changes or removes that scenario.
  The same rule the test already applies to display names of undelivered stories; the plan lists the test under
  `## Changed tests` backed by this decision, the test stage changes it, the build runs again.
- b: Keep the three browser tests in the tree until delivery and retire them in a follow-up task afterwards.
  `PayingAgainE2eTest` asserts behaviour the story removes, so it would have to be skipped or fail meanwhile.
- c: Let the gate apply the story's spec delta before it runs the suite (a pipeline change in `dca-factory`), then build again.

## Recommendation
a — it closes the gap for every story that retires a spec-named browser test, at the test that makes the rule, using
the exemption the test already grants undelivered stories for titles.

## Answer
answer: a
by: Christoph Bloemer
at: 2026-10-21T14:57:09Z
rationale: the test already grants undelivered stories this exemption for titles; the same rule then holds for every story that retires a spec-named browser test.
